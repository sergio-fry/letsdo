## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Во время выполнения агента выводятся строки действий (запуск инструмента, завершение, прочие служебные события). Перед каждой такой строкой выводить префикс времени HH:MM:SS, чтобы было видно, как давно произошло последнее действие (интервалы между действиями). Решение о том, куда идут служебные строки (stderr/отдельный поток) и как это сочетается с чистым выводом текста агента (TASK-9), принимает исполнитель — результат должен не конфликтовать с требованием «только строки агента» в stdout.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Каждая строка-действие логируется с префиксом HH:MM:SS (часы:минуты:секунды)
- [ ] #2 По префиксам можно оценить интервалы между действиями (давность последнего)
- [ ] #3 Формат префикса единый для всех действий
- [ ] #4 Префиксы HH:MM:SS применяются к строкам-действиям и сочетаются с показом параметров/результатов инструментов (актуальный TASK-9) — общий аккуратный формат
<!-- AC:END -->
