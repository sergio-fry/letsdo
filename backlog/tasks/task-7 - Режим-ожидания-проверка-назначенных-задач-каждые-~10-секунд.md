## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Когда у агента нет назначенных задач, цикл переходит в спящий режим: пауза ~10 секунд, затем повторная проверка (есть ли задачи на этого агента). Как только появляется задача — цикл запускает агента без внешнего вмешательства. Ожидание не должно жечь ресурсы (пауза сна, а не активный опрос).
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 При отсутствии задач агент не запускается, а ждёт: между проверками ~10 секунд
- [x] #2 При появлении назначенной задачи цикл запускает агента сам, без ручного вмешательства
- [x] #3 Режим ожидания не нагружает CPU (проверки раз в ~10 секунд, между ними — пауза)
<!-- AC:END -->

4. Убрать тестовую задачу, остановить цикл по SIGTERM (exit 0), зафиксировать объективные доказательства по каждому AC и финализировать TASK-7.
