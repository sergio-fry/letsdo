## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Сейчас в служебном выводе (stderr) кроме строки вызова тула 'HH:MM:SS ⚙ имя: параметры' печатается весь результат выполнения: блок строк stdout/stderr с отступом (до 100 строк / 4000 символов), заметка об обрезке и строки завершения ✓/✖ с длительностью (добавлено в TASK-22). При работе агента это нечитаемый поток: содержимое команд прочитать невозможно, информации слишком много и для наблюдения она бесполезна. Требование пользователя: показывать только сами вызовы тулов и время их выполнения — 'HH:MM:SS ⚙ имя: параметры'; тело результата (stdout/stderr) не печатать вовсе. Строки завершения с вердиктом/длительностью компактные (одна строка) — решение оставить или убрать принимает разработчик при планировании, критично: тело результата исчезает. Заодно удалить ставший ненужным код результата (truncate_result, result_note, MAX_RESULT_LINES/MAX_RESULT_CHARS, plural и т.п.) и обновить тесты.
<!-- SECTION:DESCRIPTION:END -->
